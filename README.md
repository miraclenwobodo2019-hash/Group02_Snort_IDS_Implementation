# Group02_Snort_IDS_Implementation
## Project Overview                                                                                                                          This repository contains the complete documentation, configuration files, reports, and validation evidence for the **Snort 3 Intrusion Detection System (IDS)** Capstone Project completed by **Group 02**.                                                                         The goal of this project is to design, deploy, and validate an active network threat detection environment using Snort 3 on Linux, demonstrating end-to-end capabilities in custom rule creation, live traffic analysis, and defensive security monitoring.
## Repository Structure                                                                                                                      The project is organized into the following standardized directories:                                                                       - configs/   # Snort configuration files and custom rulesets .                                                                              - docs/      # Technical guides and official project requirements .                                                                         - reports/   # Main technical documentation (.docx) and presentation slides (.pptx)  .                                                      - screenshots/  # Visual evidence of installation, traffic testing, and alert outputs .                                                     - README.md     # Repository documentation
